Standard input: a first line `N M`, then M lines `A B` meaning task A must come before task B (tasks are 0..N-1). Print a single line with an ordering of all N tasks that respects every constraint, separated by spaces, choosing the smallest-numbered available task at each step; if the constraints have a cycle, print `cycle`. 1 <= N <= 100000, 0 <= M <= 200000.
