Standard input is a sequence of commands, one per line: `insert X` adds integer X to a binary search tree (ignored if X is already there), `delete X` removes X if present, `inorder` prints the keys in increasing order separated by single spaces (an empty line if the tree is empty), `height` prints the tree's height (0 for an empty tree, 1 for a single node). Implement it as an actual (unbalanced) binary search tree of nodes; deleting a node with two children replaces its key with the smallest key of its right subtree and deletes that key from the right subtree. Up to 50000 commands; keys inserted in random order.
