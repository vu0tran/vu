Simulate an LRU cache. The first line of standard input is the capacity C (1 <= C <= 1000). Each following line is `get K` or `put K V` (K and V are integers). `get K` prints the value for K, or -1 if absent, and marks K as most recently used. `put K V` sets K to V and marks it most recently used; if that makes the cache hold more than C keys, the least recently used key is evicted (print nothing). Up to 100000 operations.
